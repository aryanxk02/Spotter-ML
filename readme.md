# Freight Rate Prediction Challenge

This project predicts the posted freight rate for truckloads using historical load data. It was completed as a machine-learning assessment involving data exploration, cleaning, feature engineering, model comparison, final prediction generation, and output validation.

## Assignment objective

The task is to train a regression model using `train-test.csv`, then predict rates for:

1. Every load in `validation.csv`.
2. Every date in the fixed December 2025 scenario in `december-chart-inputs.csv`.

The validation predictions must contain one prediction for each validation `load_id`. The December predictions must contain one positive prediction for each day from December 1 through December 31, 2025.

## Project files

| File | Purpose |
|---|---|
| `model.ipynb` | Main analysis and modeling notebook. Cleans the data, creates features, trains models, evaluates them, and writes the prediction files. |
| `score.py` | Submission checker. Validates the format, IDs, row counts, dates, and positive prediction values. It also creates the December chart. |
| `train-test.csv` | Labeled training data containing the target column `posted_rate`. |
| `validation.csv` | Unlabeled loads requiring predictions. |
| `validation-predictions-template.csv` | Template for the final validation submission. |
| `validation_predictions.csv` | Completed predictions for the 12,000 validation loads. |
| `december-chart-inputs.csv` | December scenario inputs with completed `predicted_rate` values. |
| `scorer_results/candidate_december.png` | Chart generated by the scorer from the December predictions. |
| `Report.pdf` | Assessment report containing the analysis and results. |
| `requirements.txt` | Python dependencies used by the project. |

## Modeling approach

The notebook performs the following work:

- Examines data quality, distributions, routes, equipment types, dates, and pricing behavior.
- Identifies missing and negative weight values and repairs them using equipment-level and overall medians while retaining indicator features.
- Imputes missing market-index values.
- Adds geographic distance features using the pickup and delivery coordinates.
- Adds date features including month, day of month, day of week, and day number.
- Uses a time-based validation split: data before October 1, 2025 is used for training and later data is used as the holdout period.
- Compares HistGradientBoosting and CatBoost regression models using holdout mean absolute error.
- Selects the best-performing model, refits it on all labeled data, and generates the final predictions.

## Running the project

Install the dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Run all notebook cells in `model.ipynb`. The final notebook cells generate or update:

- `validation_predictions.csv`
- `december-chart-inputs.csv`

Then validate the generated files:

```bash
python3 score.py \
  --predictions validation_predictions.csv \
  --december-predictions december-chart-inputs.csv
```

A successful run reports that it validated 12,000 final predictions and 31 December predictions, and creates:

```text
scorer_results/candidate_december.png
```
